# Market News Journal — Stage 1

Mobile-first static prototype for a daily Indian-market pre-open news journal.

## Included
- Daily report home page
- News → likely Indian market effect
- Positive / negative / neutral / high-impact filters
- Nifty levels
- Option buyer's radar
- Date-wise history
- Personal morning note saved in browser
- Sample editions for 17, 18 and 19 August 2026

## Stage 2
The next stage will connect:
- Live news sources
- Market data sources
- AI summarisation / impact analysis
- Automated 7:00 AM IST generation
- Persistent cloud database
- Post-market reality check

## Important
Do not put API keys or secrets in this repository. GitHub warns against committing passwords/API keys. Keep secrets in GitHub Actions secrets or a backend environment.
